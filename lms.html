A. Crear KV y B. Crear Worker JS

Crea la KV CONTACTOS. Crea el Worker api-contactos y pega esto:

export default {
  async fetch(request, env) {
    if (request.method === "POST") {
      const formData = await request.formData();
      const matricula = formData.get("matricula");
      
      const apiResponse = await fetch("AQUI_TU_URL_DE_GOOGLE_SCRIPT", {
        method: "POST", body: JSON.stringify({ action: "webhook", matricula: matricula })
      });
      const validacion = await apiResponse.json();

      if (validacion.status === "error") return new Response(`🛑 ACCESO DENEGADO`, { status: 403 });

      const registroFinal = {
        matricula: matricula, nombre_oficial: validacion.nombre,
        fecha: new Date().toLocaleString("es-MX", { timeZone: "America/Mexico_City" })
      };
      await env.CONTACTOS.put(matricula, JSON.stringify(registroFinal));
      
      return new Response(`✅ ¡Identidad Confirmada!\nBienvenido ${validacion.nombre}.`, { headers: { "Access-Control-Allow-Origin": "*" } });
    }
    return new Response("API Edge Activa.");
  }
};

WAF en Código + Auditoría IP

Agregamos un WAF geográfico por código. Bloquearemos tráfico extranjero y guardaremos la IP real del visitante.

export default {
  async fetch(request, env) {
    const pais = request.cf?.country || "Desconocido";
    const ciudad = request.cf?.city || "Desconocida";
    const ip = request.headers.get("CF-Connecting-IP") || "0.0.0.0";

    if (pais !== "MX") return new Response(`🛑 ACCESO DENEGADO desde ${pais}`, { status: 403 });

    if (request.method === "POST") {
      const formData = await request.formData();
      const matricula = formData.get("matricula");

      const apiResponse = await fetch("AQUI_TU_URL_DE_GOOGLE_SCRIPT", {
        method: "POST", body: JSON.stringify({ action: "webhook", matricula: matricula })
      });
      const validacion = await apiResponse.json();

      if (validacion.status === "error") return new Response(`🛑 ERROR: ${validacion.message}`, { status: 403 });

      const registroSeguro = {
        matricula: matricula, nombre_oficial: validacion.nombre,
        auditoria_edge: { ip_visitante: ip, ciudad: ciudad, fecha: new Date().toLocaleString() }
      };
      await env.CONTACTOS.put(matricula, JSON.stringify(registroSeguro));

      return new Response(`✅ Bienvenido ${validacion.nombre}.`, { headers: { "Access-Control-Allow-Origin": "*" }});
    }
    return new Response(`🛡️ Escudo Activo. IP (${ip}). Esperando Matrícula.`);
  }
};

Bonus Track Exclusivo

API RESTful Completa (CRUD)

Para graduarte como Arquitecto Backend, tu API no solo debe recibir datos (POST). Debe saber enviarlos (GET) y eliminarlos (DELETE). Vamos a crear un Dashboard de Administración para que tú mismo borres registros de tu base de datos mundial.

1. Actualizar el Worker (Soporte GET y DELETE)

export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    const corsHeaders = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "GET, POST, DELETE, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type"
    };

    if (request.method === "OPTIONS") return new Response("OK", { headers: corsHeaders });

    // CREATE (POST)
    if (request.method === "POST") {
      const formData = await request.formData();
      const matricula = formData.get("matricula");
      const registro = { matricula, nombre: "Admin", fecha: new Date().toLocaleString() };
      await env.CONTACTOS.put(matricula, JSON.stringify(registro));
      return new Response(`✅ Guardado`, { headers: corsHeaders });
    }

    // READ (GET)
    if (request.method === "GET") {
      const list = await env.CONTACTOS.list();
      let records = [];
      for (let key of list.keys) {
        const value = await env.CONTACTOS.get(key.name);
        records.push(JSON.parse(value));
      }
      return new Response(JSON.stringify(records), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
    }

    // DELETE (DELETE)
    if (request.method === "DELETE") {
      const matriculaABorrar = url.searchParams.get("matricula");
      if (matriculaABorrar) {
        await env.CONTACTOS.delete(matriculaABorrar);
        return new Response(`🗑️ Registro eliminado.`, { headers: corsHeaders });
      }
    }
    return new Response("API CRUD Activa", { headers: corsHeaders });
  }
};

En tu GitHub, crea un archivo dashboard.html y pega esto (reemplaza la URL del Worker):

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Dashboard Admin</title>
    <style>
        body { font-family: sans-serif; background: #0f172a; color: white; padding: 2rem; }
        .container { max-width: 800px; margin: auto; background: #1e293b; padding: 2rem; border-radius: 10px; }
        table { width: 100%; border-collapse: collapse; margin-top: 1rem; }
        th, td { border: 1px solid #334155; padding: 12px; text-align: left; }
        th { background: #0f172a; color: #10b981; }
        .btn-borrar { background: #ef4444; color: white; border: none; padding: 5px 10px; cursor: pointer; border-radius: 4px;}
        .btn-act { background: #3b82f6; color: white; padding: 10px; border: none; border-radius: 4px; cursor: pointer;}
    </style>
</head>
<body>
    <div class="container">
        <h1>Centro de Control REST</h1>
        <button class="btn-act" onclick="cargarDatos()">🔄 Extraer Datos (GET)</button>
        <table>
            <thead><tr><th>Matrícula</th><th>Datos</th><th>Acción</th></tr></thead>
            <tbody id="tabla-body"></tbody>
        </table>
    </div>
    <script>
        const URL = "https://TU-WORKER.TU-USUARIO.workers.dev"; // Reemplaza aquí
        
        async function cargarDatos() {
            const tbody = document.getElementById("tabla-body");
            const res = await fetch(URL);
            const datos = await res.json();
            tbody.innerHTML = "";
            datos.forEach(r => {
                tbody.innerHTML += `<tr><td>${r.matricula}</td><td>${r.fecha}</td>
                <td><button class="btn-borrar" onclick="borrar('${r.matricula}')">Eliminar (DELETE)</button></td></tr>`;
            });
        }
        async function borrar(matricula) {
            await fetch(`${URL}?matricula=${matricula}`, { method: "DELETE" });
            cargarDatos();
        }
    </script>
</body>
</html>
