Fase 05 • Backend Serverless e IAM

Worker API + Muro de los Héroes

05

Programaremos un Cloudflare Worker. Este código se comunicará vía API con el servidor maestro del instructor para validar tu Matrícula, guardará la sesión en tu propia base Key-Value (KV) y pintará tu nombre en el Muro de los Héroes proyectado en clase.

A. Crear KV

En Cloudflare: Storage & Databases > KV > Create. Nómbralo en mayúsculas CONTACTOS.

B. Crear Worker (El Validador IAM)

En Workers & Pages > Create Worker. Nómbralo api-contactos, dale Deploy y luego a Edit Code. Pega esto:

export default {
  async fetch(request, env) {
    if (request.method === "POST") {
      const formData = await request.formData();
      const matricula = formData.get("matricula");
      
      // 1. Enviar matrícula a la API del Instructor para validación
      const apiResponse = await fetch("https://script.google.com/macros/s/AKfycbyCP0zlB95ADZk1kOZ5qZFh7LSHfMUwi0S3bPFLXai2TXCQw_guuO3-PpvGf3Y_LMPPBQ/exec", {
        method: "POST",
        body: JSON.stringify({ action: "webhook", matricula: matricula })
      });
      const validacion = await apiResponse.json();

      // 2. Si la matrícula es inventada (Error 403)
      if (validacion.status === "error") {
        return new Response(`🛑 ACCESO DENEGADO: ${validacion.message}`, { 
          status: 403, headers: { "Content-Type": "text/plain; charset=utf-8" } 
        });
      }

      // 3. Si existe, guardar en tu propia Base de Datos KV
      const registroFinal = {
        matricula: matricula, nombre_oficial: validacion.nombre,
        fecha: new Date().toLocaleString("es-MX", { timeZone: "America/Mexico_City" })
      };
      await env.CONTACTOS.put(matricula, JSON.stringify(registroFinal));
      
      return new Response(`✅ ¡Identidad Confirmada!\nBienvenido ${validacion.nombre}. Tu infraestructura Edge está conectada al Muro de los Héroes.`, {
        headers: { "Access-Control-Allow-Origin": "*", "Content-Type": "text/plain; charset=utf-8" }
      });
    }

    return new Response("API Edge Activa. Esperando autenticación por Matrícula.");
  }
};

C. Vincular KV (El Paso Crítico)

CUIDADO: Asegúrate de estar en los Settings del Worker, NO de la KV.
  1. Entra a la pestaña Settings de tu Worker `api-contactos`.
  2. Ve a la sección Bindings, haz clic en + Add binding y elige KV Namespace.
  3. En *Variable name* escribe EXACTAMENTE: CONTACTOS
  4. En *KV namespace* selecciona el espacio CONTACTOS y dale al botón azul Add Binding.
  5. En la pestaña *Overview* de tu Worker, copia su URL (termina en .workers.dev).

Reto Pro

WAF en Código + Auditoría IP

PRO

Integraremos la validación de Matrícula (IAM) con un WAF geográfico por código. Así bloquearemos tráfico extranjero gratis y guardaremos la IP en nuestra base de datos.

export default {
  async fetch(request, env) {
    const pais = request.cf?.country || "Desconocido";
    const ciudad = request.cf?.city || "Desconocida";
    const ip = request.headers.get("CF-Connecting-IP") || "0.0.0.0";

    // WAF EDGE: Bloquear si NO viene de México
    if (pais !== "MX") {
      return new Response(`🛑 ACCESO DENEGADO.\nConexión desde ${pais} bloqueada.`, { status: 403 });
    }

    if (request.method === "POST") {
      const formData = await request.formData();
      const matricula = formData.get("matricula");

      const apiResponse = await fetch("https://script.google.com/macros/s/AKfycbyCP0zlB95ADZk1kOZ5qZFh7LSHfMUwi0S3bPFLXai2TXCQw_guuO3-PpvGf3Y_LMPPBQ/exec", {
        method: "POST", body: JSON.stringify({ action: "webhook", matricula: matricula })
      });
      const validacion = await apiResponse.json();

      if (validacion.status === "error") return new Response(`🛑 ERROR: ${validacion.message}`, { status: 403 });

      const registroSeguro = {
        matricula: matricula, nombre_oficial: validacion.nombre,
        auditoria_edge: { ip_visitante: ip, ciudad: ciudad, fecha: new Date().toLocaleString() }
      };
      await env.CONTACTOS.put(matricula, JSON.stringify(registroSeguro));

      return new Response(`✅ Bienvenido ${validacion.nombre}.`, { headers: { "Access-Control-Allow-Origin": "*" }});
    }
    return new Response(`🛡️ Escudo Activo. IP (${ip}). Esperando Matrícula.`);
  }
};
